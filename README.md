#Tamagotchi

Un tamagotchi hecho en html, js, y css

#Como jugar

Abre del .html con tu navegador

#Funcionalidades

Alimenta al tamagotchi, juega con el, duermelo, y despiertalo. Cada una de esas acciones suben una de las stats.

Utiliza localStorage para guardar el progreso, si borras el cache del navegador, el juego se reiniciara desde 0.

Utiliza 'alert', para avisarte de cositas.

#Script

Puedes modificarlo como quieras, las funciones tienen nombres claros de lo que hacen.
